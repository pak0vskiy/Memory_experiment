# Invitation messages for participants

Ready to paste into KakaoTalk, Telegram, WhatsApp etc. Each message is the same in every language.

What they deliberately do **not** say, so the results stay clean:
- which method we expect to work better (that could change how much effort people put into each);
- what the texts are about (people could read up on the topic beforehand).

Replace the link if the address changes. Session times: ~15 / ~15 / ~10 minutes.
